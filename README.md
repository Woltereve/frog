 Frog – Page de contact

Reproduction fidèle d'une maquette de page de contact, réalisée dans le cadre d'un test technique.

Outils utilisés

VS Code : tout le code a été écrit à la main dans l'éditeur.
MDN Web Docs : référence principale pour les balises, les attributs et les propriétés CSS.
Validateur W3C: vérification de la validité du HTML.
Git / GitHub :  publication du projet.
Iconify (et autres bibliothèques) : recherche des icônes.
